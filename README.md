✈️ Aircraft Predictive Maintenance Dashboard

An interactive Power BI dashboard designed to analyze aircraft maintenance data and provide predictive insights for proactive maintenance planning.

🚀 Features
- Aircraft health monitoring
- Maintenance trend analysis
- KPI tracking and visualization
- Predictive maintenance insights
- Interactive dashboards and reports

🛠️ Tech Stack
- Power BI
- DAX
- Power Query
- Data Visualization

📊 Project Outcome
Enabled data-driven maintenance decisions by identifying potential failures, reducing downtime, and improving operational efficiency.
