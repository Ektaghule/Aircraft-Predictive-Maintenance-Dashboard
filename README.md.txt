# Aircraft Predictive Maintenance Dashboard

## Overview
This project presents a Power BI dashboard designed to analyze aircraft maintenance data and provide predictive insights for maintenance planning and fault detection.

## Features
- Interactive Power BI Dashboard
- Aircraft Health Monitoring
- KPI Tracking and Visualization
- Failure Trend Analysis
- Predictive Maintenance Insights
- Dynamic Filters and Drill-Through Reports

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Analytics
- Data Visualization

## Project Outcome
The dashboard helps identify potential equipment failures, optimize maintenance schedules, and reduce unplanned downtime through data-driven insights.
